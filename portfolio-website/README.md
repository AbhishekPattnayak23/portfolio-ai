# Portfolio Website

A modern portfolio website built with React, TypeScript, and Vite.

## Features

- Responsive design
- Project showcase with filtering
- Skills and experience sections
- Contact form
- Type-safe development with TypeScript

## Technology Stack

- React 18
- TypeScript
- Vite
- React Router
- Styled Components
- ESLint & Prettier for code quality
- Jest for testing
